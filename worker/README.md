# Стена razrad — бэкенд (Cloudflare Worker + KV)

Файлы этого сайта статические (GitHub Pages), поэтому сообщения стены хранит
Cloudflare Worker. Фронт (`script.js`) ходит в него по адресу `WALL_API`.

## Что делать (в браузере, 5 минут)

1. Открой **dash.cloudflare.com** → **Workers & Pages** → твой воркер
   `razrad-dashboard` → **Edit code**.
2. Удали всё содержимое редактора и вставь всё содержимое файла
   `worker/wall-worker.js` из этого репозитория.
3. Нажми **Deploy**.
4. Проверь, что он отвечает:
   `https://razrad-dashboard.ТВОЙ-ИМЯ.workers.dev/api/ping`
   должно вернуть `{"ok":true,"service":"razrad-wall",...}`

Переменные (`Settings → Variables and Secrets`) должны остаться как есть:
- `WALL` — KV namespace (8776a0ccbe72458a877df18cfa3e5448)
- `WALL_SECRET` — секрет (именно он подписывает капчу и хранит пароли;
  если его сменить, все записанные пароли перестанут подходить)

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET  | `/api/ping`     | проверка живости |
| GET  | `/api/config`   | лимиты (задержка, макс. длина) |
| GET  | `/api/captcha`  | ретро-капча: `{ svg, token }`, ответ подписан HMAC, TTL 5 минут |
| GET  | `/api/posts`    | последние сообщения |
| GET  | `/api/nick?nick=` | занят ли ник |
| POST | `/api/post`     | отправить сообщение (ник, пароль, текст, капча, `t0`, `hp`) |
| POST | `/api/delete`   | удалить свой пост (ник + пароль) |
| POST | `/api/wipe`     | удалить все посты ника (ник + пароль) |

## Как устроена защита

- **ник + пароль.** Ник свободен — пароль задаётся тобой при первом посте и
  больше не меняется. Писать с любого устройства можно, зная пароль.
  Пароль хранится только как `sha256(соль + пароль + WALL_SECRET)`.
- **капча** рисуется воркером как SVG (серый фон, шум, линии, повёрнутые
  буквы) — весит 0 байт и не грузится со стороны. Ответ подписан HMAC и живёт
  5 минут, подделать нельзя.
- **honeypot** — скрытое поле `wallHp`, которое заполняют боты.
- **время на форме** — сервер требует, чтобы форма была открыта ≥ 3 секунды.
- **задержка 15 минут** на ник (одно сообщение).
- **не больше 10 сообщений в час** с одного IP и 5 новых ников в час.
- **не больше 6 неверных паролей** на ник в час (защита от перебора).

## Ключи в KV

| ключ | что |
|---|---|
| `posts` | массив последних 400 сообщений |
| `nick:<ник>` | `{ s: соль, h: хеш пароля, c: когда создан }` |
| `rl:<ник>` | время последнего сообщения (задержка 15 мин) |
| `bad:<ник>` | неудачные попытки ввода пароля |
| `ip:<хэш>` / `nk:<хэш>` | окна лимитов по IP |

## Локальные тесты (без Cloudflare)

```bash
python tools/serve.py 8850        # threaded-сервер в корне проекта
```

- `tools/wall_test.html` — 28 проверок самого воркера (мнимый KV, настоящий
  Web Crypto). Открыть `http://127.0.0.1:8850/tools/wall_test.html`.
- `tools/captcha_look.html` — три капчи подряд, глазами проверить читаемость.
- `python tools/make_wallmock.py` — собирает `_wallmock.html`: та же страница,
  но запросы идут в локальный мок этого же воркера. Проверяет весь сценарий
  отправки без деплоя.
